# infiniti-customer-segmentation

## Overview
This project analyzes customer perceptions of the Infiniti G20 using PCA, regression, and segmentation techniques to recommend a repositioning strategy.

## Objective
The goal of this project was to understand how customers perceive the Infiniti G20 relative to competitors and identify the most suitable target segment for repositioning.

## Methods Used
- Principal Component Analysis (PCA)
- Regression Analysis
- Customer Segmentation
- Perceptual Mapping

## Dataset
The analysis is based on:
- Brand attribute ratings dataset
- Individual respondent dataset

## Files in this Repository
- `infiniti_g20_analysis.ipynb` – main analysis notebook
- `File1_Brand_Attribute_Ratings.xlsx` – brand attribute ratings data
- `File2_Individual_Respondent_Data.xlsx` – respondent-level data
- `Consumer analytics - Infiniti G20 ...` – project report

## Key Insights
- Evaluated 15 brand attributes across multiple customer perceptions
- Identified 3 major customer segments
- Used PCA and regression to understand positioning and attribute importance
- Recommended a repositioning strategy for the Infiniti G20 toward value-conscious performance seekers

## Tools Used

- Excel

## Outcome
This project demonstrates how statistical and analytical techniques can support brand strategy and customer segmentation decisions.
